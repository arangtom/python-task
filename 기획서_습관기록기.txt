잔디(히트맵)형 습관·공부 기록기 기획서

작성자: 이아랑 | 작성일: 2026년 11월 25일

1. 프로젝트 개요

- 프로젝트명: 잔디(히트맵)형 습관·공부 기록기 (habit-heatmap)
- 한 줄 소개: 오늘의 할 일을 적고 완료하면 달성률이 자동으로 계산되고, 그 결과가 월별 달력의 색으로 채워지는 시각적 습관 트래커
- 개발 환경: Python 3.8 이상, 외부 라이브러리 없이 표준 라이브러리만 사용, VS Code 터미널에서 실행
- 배포 방식: GitHub 레포지토리에 소스 코드와 README 공개 (필요 시 PyInstaller로 exe 변환)

2. 기획 배경 및 목적

대학 생활을 시작하면 수업, 과제, 시험, 자격증 준비를 동시에 해야 하지만, 계획을 세우고도 실제로 얼마나 실천했는지는 확인하기 어렵습니다. 반면 GitHub의 잔디처럼 하루하루의 활동이 색으로 쌓이는 방식은 꾸준함을 한눈에 보여 주어 지속적인 동기를 만들어 줍니다.

본 프로젝트는 이러한 방식을 학습·습관 관리에 적용하여 다음을 목표로 합니다.

- 매일의 할 일 완료 여부를 간단한 명령어로 기록한다.
- 달성률을 자동으로 계산해 사용자가 직접 계산하는 번거로움을 없앤다.
- 한 달 단위의 달력 히트맵으로 실천 현황을 직관적으로 보여 준다.
- 직접 개발하고 GitHub에 공개하면서 Python 프로그래밍과 버전 관리 경험을 쌓는다.

3. 대상 사용자

- 학업과 자기계발 계획을 꾸준히 실천하고 싶은 대학생
- 별도의 앱 설치나 회원가입 없이 가볍게 쓸 수 있는 기록 도구를 원하는 사용자
- 코드를 직접 읽고 수정하며 Python을 배우고 싶은 입문 학습자

4. 핵심 기능

4.1 할 일 관리

- add: 오늘 또는 지정한 날짜에 할 일 추가 (예: add 리포트 쓰기)
- list: 남은 할 일과 달성률 막대 확인 (list --all로 완료한 일까지 확인)
- done: 완료 처리. 완료한 일은 목록에서 사라지지만 기록은 유지되어 달성률 계산에 반영
- undo / remove: 완료 취소, 잘못 적은 할 일 삭제

4.2 달성률 자동 계산

- 하루 달성률은 완료한 할 일 수를 전체 할 일 수로 나눈 값입니다. 예를 들어 5개 중 3개를 끝내면 60%입니다.
- 완료한 일을 목록에서 완전히 지우지 않고 기록으로 남기는 이유는, 지워 버리면 전체 개수가 줄어 달성률이 실제보다 높게 계산되기 때문입니다.

4.3 직접 기록

- goal로 하루 목표를 정하고 log로 공부 시간 같은 숫자를 기록할 수 있습니다.
- 같은 날 할 일과 직접 기록을 모두 사용하면 달성률이 더 높은 쪽이 히트맵에 반영됩니다.

4.4 월별 달력 히트맵

- show: 이번 달 또는 지정한 달(show 2026-10)의 달력을 터미널에 색상으로 출력
- html: 최근 6개월(기간 변경 가능)을 월별 카드로 보여 주는 웹 페이지 생성. 칸에 마우스를 올리면 날짜와 달성 내역 확인
- 오늘 날짜는 굵게 강조하고, 아직 오지 않은 날은 흐리게 표시
- 한 달씩 끊어 보여 주어 1년치를 한 줄로 늘어놓는 방식보다 가시성이 높음

4.5 통계

- 이달 목표 달성일 수, 평균 달성률, 현재 연속 달성일(streak)을 함께 표시

5. 색상 단계 기준

- 0단계: 기록 없음 (회색)
- 1단계: 달성률 1% ~ 32%
- 2단계: 달성률 33% ~ 65%
- 3단계: 달성률 66% ~ 99%
- 4단계: 달성률 100% 이상 (목표 달성, 가장 진한 초록)

6. 사용 시나리오

1. 아침에 오늘 해야 할 일을 add 명령어로 3~5개 등록한다.
2. 하루 동안 일을 마칠 때마다 done 명령어로 완료 처리한다.
3. 저녁에 list로 남은 일과 달성률을 확인한다.
4. show 또는 html로 달력을 열어 오늘 칸이 어떤 색으로 채워졌는지, 이번 달 연속 기록이 어떤지 확인한다.
5. 한 달이 지나면 지난달 달력을 보며 실천 패턴을 돌아본다.

7. 시스템 구조

- 구성: 단일 파일 habit_tracker.py에 모든 기능을 구현하고, argparse로 명령어를 처리합니다.
- 사용 모듈: argparse, calendar, json, datetime, pathlib, webbrowser (모두 Python 표준 라이브러리)
- 데이터 저장: 실행 폴더의 habit_data.json 파일에 하루 목표(goal), 직접 기록(records), 날짜별 할 일(todos)을 저장합니다.
- 개인정보 보호: 개인 기록 파일은 .gitignore에 등록하여 GitHub에 올라가지 않도록 합니다.
- 이전 버전의 기록 파일도 그대로 읽을 수 있도록 하위 호환성을 유지합니다.

9. 기대 효과

- 사용자는 하루 실천 여부가 색으로 쌓이는 것을 보며 꾸준히 이어 가려는 동기를 얻을 수 있습니다.

10. 한계 및 향후 개선 계획
